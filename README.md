## 📋 Sobre o Projeto

Dashboard desenvolvido no Power BI focado na análise de indicadores administrativos e financeiros, transformando dados brutos em insights visuais para tomada de decisão: visão geral de vendas, custos e lucro, e comparativo de desempenho mensal e anual.

## 🛠️ Tecnologias Utilizadas

- **Power BI** (criação de dashboards e tratamento de dados com Power Query)
- **SQLite** (fonte de dados original)
